# 깃 연결

## 최초 1회

```
git pull origin main --allow-unrelated-histories 
git remote remove origin
git remote add origin 저장소주소
```

## 커밋 및 푸시

```
git add .
git commit -m "커밋 메시지" 
git branch -m master main #(1회만 사용)
git push -u origin main
```
